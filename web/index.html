Media player

Network

What Bonjour tells the player to connect to. Mitti uses the first address it is given, so on a machine with a VPN (ZeroTier, Tailscale) pick the show network's address here.

Feedback relay destinations
NameAddressPortOn

Every feedback packet the player sends is re-sent, byte for byte, to each destination — for Mitti, Companion's Mitti module (port 51001), a Stream Deck, another machine.

Switcher

Emulated ATEM (the player's ATEM integration)

The player sees an ATEM whose inputs are the switcher's inputs and whose program/preview follow the real switcher. In Mitti, choose it under ATEM, pick the input it is on, and set its switch behaviour; Mitti's Pause-at-End CUT/AUTO fires a take on the real switcher. Uses UDP 9910 — do not run it on a machine that is also an ATEM's control computer with ATEM Software Control connected to a real one on the same port.

NDI tally (the player's NDI integration)

automitti joins the player's NDI output as a metadata-only receiver (no video) and reports it on program while the player's switcher input is on air. In Mitti, set the integration to NDI.

Rules — automitti drives the player directly

The same choices Mitti offers for an ATEM, run from here through the player driver — for when the player is not using its own ATEM or NDI integration. Don't enable rules while the player's own ATEM/NDI trigger points at automitti, or both will act on every take.
